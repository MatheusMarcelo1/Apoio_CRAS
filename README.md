# Apoio CRAS

Conjunto de softwares, scripts e ferramentas desenvolvidos para apoiar as atividades do **CRAS**, incluindo automação de processos, geração de documentos, gerenciamento de arquivos e soluções para otimizar as rotinas administrativas.

Este repositório reúne diferentes projetos e utilitários desenvolvidos para facilitar, organizar e automatizar tarefas do dia a dia, contribuindo para maior eficiência e praticidade na execução das atividades.
